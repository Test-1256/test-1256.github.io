This applet can animate in realtime a popular artificial life algorithm, 
where some "flozoids" are flying around. 

This applet is fully parametrized, so you can change many things to adapt 
the effect to your pages and purposes.

I have to thank Jeff Cragg and Alex Vulliamy for this idea.

*************************************************************************

NECESSARY FILES.

Apart from the background and/or foreground image, the following 2 ".class" 
files must be uploaded: 

flozoids.class
Lware.class

Plus, flozoids.jar for speedy loading on recent browsers.

*************************************************************************

EXAMPLE.

Insert the <applet></applet> tag in your html document as follows to add 
this applet to your page (Comments after the ";" symbol are code descriptions
 and acceptable min/max values. They are not part of the applet language):


<applet archive="flozoids.jar" code=flozoids.class width="150" height="200">
<param name="credits" value="Applet by Fabio Ciucci (www.anfyteam.com)">
<param name="regcode" value="NO">          ; Registration code (if you have it)
<param name="reglink" value="NO">          ; Optional URL link when the applet
                                           is "clicked".
<param name="regnewframe" value="YES">          ; Reglink opened in new frame?
<param name="regframename" value="_blank">      ; Name of new frame for reglink
<param name="statusmsg" value="Flozoids applet">  ; Statusbar message
<param name="numfloz" value="50">          	; Number of flozoids
<param name="flozdistance" value="200">    ; Distance allowed between flozoids
<param name="tocenter" value="20">         ; Tendency of flozoids moving toward center
<param name="acceleration" value="30">     ; Acceleration of flozoids
<param name="speed" value="5">             ; Speed of flozoids
<param name="sidebouncing" value="80">     ; Side bouncing factor
<param name="fheads" value="YES">          ; Flozoids have heads? ("YES", "NO")
<param name="interactive" value="YES">     ; Interactive mode ("YES", "NO")
<param name="overtext" value="YES">        ; Flozoids go over text? ("YES", "NO")
<param name="backimage" value="NO">        ; Background image (it's name or "NO")
<param name="backR" value="0">             ; Background colour (red component)
<param name="backG" value="0">             ; Background colour (green component)
<param name="backB" value="0">             ; Background colour (blue component)
<param name="flozR1" value="255">          ; Flozoids colour1 (red component)
<param name="flozG1" value="240">          ; Flozoids colour1 (green component)
<param name="flozB1" value="240">          ; Flozoids colour1 (blue component)
<param name="flozR2" value="60">           ; Flozoids colour2 (red component)
<param name="flozG2" value="70">           ; Flozoids colour2 (green component)
<param name="flozB2" value="80">           ; Flozoids colour2 (blue component)
<param name="overimg" value="NO">          ; Optional image over applet
<param name="overimgX" value="0">          ; Over image X offset
<param name="overimgY" value="0">          ; Over image Y offset
<param name="memdelay" value="1000">       ; Memory deallocation delay
<param name="priority" value="3">          ; Task priority (1..10)
<param name="MinSYNC" value="10">          ; Min. milliseconds/frame for sync
Sorry, your browser doesn't support Java.; Message for no java browsers.
</applet>                                ; End of applet tag

INSTRUCTIONS.


The following instructions describe how to change parameters:

Attempting to change the credit parameter will disable the applet.

To activate the reg parameters read the shareware registration notes.
In the "regcode" parameter, place the registration code you purchased 
from the author. If the code is correct and the applet is run from the
 registered domain name, you can use "link" parameters to link to a URL
when the applet is mouse-clicked.

If you set "regnewframe" to "YES", you can specify a specific frame location
for the reglink:

"_blank"  : To load the link in a new blank unnamed browser window.
"_self"   : To load the link into the same window the applet occupies.
"_parent" : To load the link into the immediate FRAMESET parent.
"_top"    : To load the link into the top body of the window.

You can also set a custom frame name, such as "myframe1".

With the "overimg" parameter you can specify the name of an image that will
be painted over the applet. The best options are transparent GIF images.
NOTE: Animated GIF images are supported, but will be animated only on latest
 browsers (Netscape 4 and Explorer 4 or newer).

With "overimgX" and "overimgY" you can center the image over the applet area.

The size of the applet is determined by width and height tags.

The number of flozoids is determined by the "numfloz" parameter: more
flozoids mean slower execution.

The behaviour of flozoids can be altered with these parameters:

"flozdistance" : determines how far a flozoid can go from other flozoids
"tocenter" : determines the tendency to go to the center of the applet area
"acceleration" : determines the acceleration of flozoids' motion
"speed" : determines the max speed a flozoid can reach
"sidebouncing" : determines the intensity of bouncing when edges of the
                 applet are reached.
"fheads" : determines if flozoids have heads or not.
"overtext" : determines if flozoids can overwrite a scrolling text.

If you set the "interactive" parameter to "YES", flozoids will follow
the mouse pointer, when it enters in the applet area.

You can change the colour of flozoids for best results on your web page. 
The RGB values are the same as those in HTML tags, but in pure decimal values
without the "#" symbol.

Use backR,backG,backB to change background colour.

If you want to display an image in the background, place its name in the
place of "NO" at backimage parameter (for example "back.jpg").

The only requirement is that the background image must be the same size as
the applet to completely cover it.

You can choose the first and last colour of a gradient effect that is spread
over all the flozoids: flozR1,flozG1,flozB1 for first colour, flozR2,flozG2,
flozB2 for the last colour of the gradient. Examples: to make ALL the flozoids
white, place 255 as value for all the flozR1,flozG1,flozB1 and flozR2,flozG2,
flozB2.

Eg.

To make flozoids colour go from  black to white (all the intermediate grays),
place a value of 255 for flozR1,flozG1,flozB1 and a value of 0 for the second
color: flozR2,flozG2,flozB2.
You can also make various rainbows (from red to blue, etc.).
