Stormrunner cannot be installed in this browser, but it can be loaded and played, with the exception that loading and saving games will not work!

Please be patient, the loading process can take a long time. When the "Start Game" button appears below, press it to start the game.


Macintosh users: Due to a bug in Apple's support for Java, You may need to wait until the applet loads, and then repetitively click on the blank space above in order for the "start game" button visible. If pressing the "Start Game" button does not start the game, or you see an error message, please read these notes about using Stormrunner on a Macintosh.
