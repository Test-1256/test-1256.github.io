PLATFORM INCOMPATIBILITY

Unfortunately, your browser and/or operating system are unsupported for purposes of playing Stormrunner.

At this time, the supported platforms on which to play Stormrunner are:
  • Windows 95, 98, or NT4
    • Internet Explorer 4.0 or newer
    • Netscape 4.06 or newer
  • MacOS
    • Internet Explorer 4.0 or newer using Apple's MRJ
Other Java 1.1-capable web browsers on other operating systems (for instance, Netscape under Linux) may work, but we cannot test all of the various possibilities, and we can make no guarantees. You may attempt to proceed and use the game anyway, but it may not function properly, or at all. In addition, if you are able to access the game by following this link, the game will not be able to install itself on your computer to avoid future downloads, and you will not be able to load or save games.

Mozilla/Netscape 6 users (or others using a Java 1.2 plugin): We have tested it, and seems to work. However, we have not added support for the Sun security mechanism, so as with other unsupported browsers, the game will not install, and you will not be able to load or save games.

Try the game anyway.
