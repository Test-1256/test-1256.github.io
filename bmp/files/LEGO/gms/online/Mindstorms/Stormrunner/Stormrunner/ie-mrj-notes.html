STORMRUNNER FOR THE MACINTOSH

You'll need the most recent version of Internet Explorer and Apple's Java classes to play STORMRUNNER. It appears that you have both, but if you are experiencing trouble, make sure that you have:

  • The current version of Microsoft's Internet Explorer (or at least version 4.5).
  • Apple's newest version of the MRJ.
    • Once you have downloaded the MRJ, install it, and then go into your Internet Explorer preferences (under the Edit menu). Under Java, select the "Apple MRJ" as your Java Virtual Machine, then quit and re-open your browser.
Once you are certain you have the current version of each of these products, and that Apple's MRJ is properly installed and selected in your Java preferenes, you must also make certain that the following options are selected in the Java section of your Internet Explorer preferences:
  • "Enable Java" is checked
  • "Network access" is set to "Applet Host Access"
  • "Restrict access to non-Java class files" is NOT checked
If you are certain all of these conditions are satisfied, but you are still unable to play the game, please write to bugs@legomindstorms.com and we will try to help.
