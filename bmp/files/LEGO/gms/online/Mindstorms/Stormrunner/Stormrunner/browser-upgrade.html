UPGRADE REQUIRED!

Stormrunner uses Java 1.1. Generally, that means you need to be running at least Microsoft Internet Explorer 4.0 or Netscape Communicator 4.06 to play.

For both your security and convenience, you should always use the most recent web browser available from your vendor of choice.

If you are using Netscape 4.06 or better and have disabled Java in your preferences, you must re-enable it, come back, and try again.

If you are using Internet Explorer (and are using an older Windows 95 computer, perhaps?), but you are still getting this message, the Microsoft Virtual Machine has not been installed on your computer. You should visit Microsoft Windows Update and download all the supplied updates to your browser and operating system, including the Microsoft Virtual Machine. Then come back and try again. (You can also use Netscape 4.06 or better instead - it should also work.)
