Anfy Resources for 2.x Wizard

This set of documents provides you minimum information to work with Anfy applets and the 2.x wizard, either Win32 or Macintosh PPC program.

It is highly recommended that you should at least take a look at Quick Start section before start editing your HTML page with an applet.

For each applet, we have provided two types of tutorials; one you can find in Applet Tutorial section in this help and the other in the form of simple texts, which can be found in each applet folder. The former is designed for beginners and you are not required to understand HTML scripting to read this; whereas the latter readmes are extensive source for HTML scripting. So, if you are only concerned about "visual" configuration of an applet with the wizard, just read the applet tutorial section and find an appropriate applet tutorial.

When you experience technical problems, you should first consult the Technical Support section and read General FAQ page. This will solve most problems. After that, if you still have problems unsolved, please feel free to contact us.
