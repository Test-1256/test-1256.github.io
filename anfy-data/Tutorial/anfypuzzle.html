Applet Tutorial: Anfy Puzzle

This applet is a game where the user has to recompose a picture, divided into tiles like a puzzle within a certain time.

[For more technical information about the available parameters, click here.]

Most parameters are self-explanatory and you can always see brief description of each parameter by moving the mouse pointer over the wizard.

Basic Setting

Define the Resolution and the applet Width and Height. Resolution is a zooming factor. For instance, if resolution is 2, the applet size is doubled. The recommended value for resolution is always 1. This produce the highest image quality. Check Enable textscroll, if necessary. Select either Background image or Background color. Optionally, you could set the Introduction image, which loads before the game starts.

Puzzle

Set Puzzle Images using Add, Move Up, Move Down, and Remove buttons. You can set as many images as you prefer, though the minimum number of images is 2. Set the XY Offset values for the puzzle image, and define the number of horizontal and vertical tiles at Tiles XY. The minimum is 2. Optionally, you could enable shadow effect for the tiles by selecting Shadow box. The puzzle images load according to the stacking order displayed in the puzzle image box, however, if Random Order box is checked out, the order becomes randomized. Now, you could set the time limit at Total seconds, within which user has to complete the first game. At Loading message box, you could enter the message which is shown as images being load. Finally, select the Font and the Font Size for the message.

Proceed to the textscroll menu if you have checked the textscroll box; otherwise go to the expert menu.
