Applet Tutorials: Banner/Slide show
 
This category includes 3 applets, i.e., bookflip, cfade, mosaic in particular. Now look at each applet and select one to proceed for detailed applet specific instructions.

(1) Bookflip applet

This applet displays series of images at a desired speed. Each image can be assigned a unique url so that you can use this applet as a menu.

(2) Cross-fade applet

This applet executes cross-fade between images which have to be the same size. As the same above, you can use this as a graphical menu.

(3) Mosaic applet

This applet displays slideshow with tiling transitions. This works as a menu, too.
